What these rules do

1Send the closest available lift to a newly pressed up/down hall button.
2Queue each passenger's destination when they board.
3When idle, travel to the next passenger stop or nearest waiting call.
4Open doors whenever the lift reaches a target floor.
Available events

When can a rule fire?

Events are emitted by the building or by a lift. Some include context such as the called floor or a passenger's chosen destination.

On StartOn IdleOn Up Button PressedOn Down Button PressedOn Floor Button PressedOn Passing FloorOn Stopping At Floor
Parameter links

Give an action its value

For actions that need a floor, use the parameter dropdown: for example Go to floor ← Current floor + 1, or Queue floor ← Passenger destination.

Tip: start with the default controller, run a test, then change one rule at a time to see how it affects transport and waiting time.
